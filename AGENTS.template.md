Shared skills are located at ~/skills (/home/ekalkutin/skills)

Workflow:

1. Understand the task.
2. Read ~/skills/INDEX.md.
3. Select candidate skills.
4. Read each candidate's meta.yaml.
5. Load SKILL.md only if the metadata matches the task.
6. Never load unrelated skills.
7. Keep the number of loaded skills to a minimum (typically 2–5).
